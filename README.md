## Nearby

<table>
<tr>
<td width="52%"><img src="docs/images/nearby.png" alt="Nearby players"></td>
<td>

Turn on **Nearby** and the players around your character appear on their own — enemies and allies,
each with their power and gear score, in towns, in the open world, in Shugo and in the arena.

**Recent** keeps everyone you've crossed paths with — as many as you like — with when you last saw them
and a ⚔ for anyone who fought you.

**PVP** logs who you killed, who killed you, your assists and your duels, with kills, deaths and K/D for any
dates you pick. Click anyone to see every fight you've had with them.

**Pop out** any tab (right-click it) into its own slim window over the game: Nearby and PVP as compact HUDs,
each with its own opacity, click-through and lock. An **Enemy Alert** can play a sound when an enemy shows up.

<sub>Opt-in. Reads the game's network traffic on your PC through Windows itself — nothing extra to install. It never sends or changes anything.</sub>

</td>

## Getting Started

**Windows**

1. **[Download Shugo Tracker for Windows](https://github.com/CynicaGaming/Shugo-Tracker/releases/download/v2.8.0/Shugo-Tracker-2.8.0-Windows.exe)** and put it in a folder of its own.
2. Run it. Windows may show a SmartScreen warning the first time — choose **More info → Run anyway**.
3. Play the game in **borderless windowed** mode so the tracker can sit on top.

**Android** (8.0 or newer)

1. On your phone, **[download Shugo Tracker for Android](https://github.com/CynicaGaming/Shugo-Tracker/releases/download/v2.8.0/Shugo-Tracker-2.8.0-Android.apk)**.
2. Open it. The first time, Android asks you to allow installs from your browser — allow it, then tap **Install**.

## Frequently Asked Questions

<details>
<summary><b>Is it safe? Will it get me banned?</b></summary>
<br>
Search and profiles only use NCSOFT's public website data, the same as looking someone up in a browser.
Nearby is different: it reads the game's network traffic on your own PC. It never sends, changes or injects
anything, but reading game traffic may still be against AION 2's Terms of Service. Use Nearby at your own risk;
Shugo Tracker isn't responsible for any action taken against your account.
</details>

<details>
<summary><b>Why isn't the Android app on Google Play?</b></summary>
<br>
It's installed straight from the releases here instead, like the Windows app. Android calls that an "unknown app" and asks
once before installing it; after that, updates come from inside the app (Settings → Updates).
</details>

<details>
<summary><b>What does Share Usage Statistics send?</b></summary>
<br>
Twice a day: a random id the app makes up for itself, the app version, Windows or Android and its version, the display
language, how many times a few features were used (searches, profiles opened, favorites added, Nearby turned on,
pop-outs, the PVP Log, updates), whether Nearby is on and how many favorites and own characters are saved. It never
sends character names, what you search for, your server or anything from the game, and the server keeps no IP
addresses. It's on unless you turn it off in <b>Settings → Privacy</b>; turning it off stops it at once.
</details>

<details>
<summary><b>Why does Windows warn me when I run it?</b></summary>
<br>
The exe isn't code-signed yet, so SmartScreen doesn't recognise it. The code is all here in this repository,
and every release is built automatically from it.
</details>

<details>
<summary><b>Where are my settings and favorites?</b></summary>
<br>
On Android, inside the app (uninstalling it removes them). On Windows:
in the <code>data</code>, <code>cache</code> and <code>logs</code> folders next to the exe (the <code>app</code> folder
is the program itself, unpacked the first time each version starts). Updates only replace the exe, so nothing is lost;
move or copy the whole folder to take everything with you.
</details>

<details>
<summary><b>Why does Nearby need administrator?</b></summary>
<br>
Windows only lets programs running as administrator read network traffic, and Windows Firewall has to let the
game's traffic through to it, so the first time Nearby starts, Shugo Tracker adds one firewall rule allowing
itself in ("Shugo Tracker (Nearby)"). Search, profiles and favorites never need administrator. To skip the restart each time, right-click the exe → <b>Properties</b> →
<b>Compatibility</b> → <b>Run this program as an administrator</b>. Each update gives the exe a new name (its version), so tick it again after updating.
</details>
